## Rules
- One task = one implementer invocation. Keep tasks small.
- A task is `done` only when the docs/DefinitionOfDone.md Gate checklist passes and quality-assurance returns GO.
- T1(I/O 스키마 합의)이 완료되기 전에는 T5 이후의 기능 태스크를 시작하지 않는다. 스키마 불일치는 통합 단계 재작업의 최대 원인이다.

- **T41·T42(쌍방 규약)의 착수 조건은 해소되었다** — PRD Open Question #16이 2026-08-04에 **병행**으로 확정(`answered`)되었다. T19·T20·T21은 범위 변경 없이 그대로 유지하며, 규약은 상대별 데이터로 **별도 저장**하고 충돌 시 규약이 우선한다(PRD Planning Decision #26). 우선순위는 **P2 유지, 승격 없음**.
