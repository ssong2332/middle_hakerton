## 3. 차별화 KEY 3개 (T37 요구사항 ②, PRD Differentiation 3절 그대로 인용 — 신규 문구 생성 없음)

| KEY | 확정 문구 |

| KEY 1 | **"톤 교정"이 아니라 "번역 손실 방지"** — 경쟁사는 polish를, 우리는 preserve를 판다. 근거: C4 역번역 + C2 긴급도 보존 필터 + C5 용어사전 |
| KEY 2 | **"추론으로 시작하고, 합의로 확정한다"**(PRD Planning Decision #97, v2.8 최신 문구). 확정 발표 문구: *"다른 도구는 당신을 추측해서 조용히 적용합니다. 우리는 추측한 근거를 보여주고, 두 사람이 확정한 것만 규칙으로 남깁니다."* ⚠️ v2.3 폐기 문구("우리는 추론하지 않습니다...")는 **절대 사용 금지**. 컷 조합 4가지(#24·#34 생존 여부)에 따라 이 KEY의 발표 축이 달라짐 — PRD Planning Decision #98 표를 그대로 따른다 |
| KEY 3 | **개인 간이 아니라 "조직 간" 마찰** — C6(하소연→티켓, 데모 하이라이트) · 층 1 범용 오버레이(#32) · Gmail 어댑터(#31) 근거. Slack AI는 Slack 안에서만, Tonero는 명시된 사이트 목록에서만 동작(measured) — 우리 층 1은 대상 사이트 식별 없이 동작 |

**발표 위상 준수 체크(요구사항 ③)**: C7은 차별점으로 내세우지 않음(Decision #46) / C6은 데모 하이라이트(#47) / R2는 보조 기능으로만 언급(#48).
